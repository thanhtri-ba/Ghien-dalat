# Ghien-dalat (Overland Travel)

Web application and platform for Dalat overland travel experiences.

## Project Structure

- `frontend/`: React + Vite frontend application.
- `backend/`: Node.js Express backend server and SQLite database.
- `overland-travel.html`: Standalone landing page.

## Getting Started

### Backend
```bash
cd backend
npm install
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
